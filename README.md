# Bot de Suporte SEDEL

Sistema de suporte técnico para registro e acompanhamento de chamados da Secretaria de Estado de Desporto e Lazer (SEDEL).

## Tecnologias

- Node.js
- Express
- SQLite
- HTML
- CSS
- JavaScript

## Instalação

```bash
npm install
```

## Execução

```bash
npm start
```

## Funcionalidades

- Registro de chamados
- Atendimento automatizado
- Classificação de chamados
- Histórico de conversas

frontend/
